# 视频自动循环监控压缩工具 (Auto Video Compressor)

基于 PySide6 + FFmpeg 构建的高效视频自动化监控与压缩工具，专为多设备同步（Syncthing）、边录边传及大批量视频自动压制场景设计。

## 🌟 核心特性

- **递归巡检与定时循环**：支持对目标文件夹及其所有子目录进行自动化定时扫描。
- **4 重 Syncthing & 边录边传防护**：
  1. **临时/中间文件过滤**：自动跳过 `.syncthing.`、`.tmp`、`.part` 等中间同步文件；
  2. **句柄独占测试**：检测文件是否处于写入或独占锁定状态；
  3. **修改时间冷却判定**：可配置 `mtime` 冷却安全期（默认 180 秒 / 3 分钟），未稳定文件暂不处理；
  4. **容器完整性探针**：通过 `ffprobe` 深度校验 MKV/MP4 容器完整性与索引结构。
- **绝对排重与产物泛匹配**：识别 `(ys)` 输出产物前缀，防止视频被二次重复压缩。
- **UI 优化与实时进度**：跨线程 Qt Signal 安全通信，精简表单，原生单进度条实时渲染。
- **硬件加速支持**：内置 NVIDIA NVENC 硬件加速及 CPU 软解回退机制。

## 🛠️ 项目结构

```
视频自动循环监控压缩工具/
├── bin/                       # 存放 ffmpeg.exe, ffprobe.exe
├── config.py                  # 配置文件与数据结构定义
├── compressor.py              # FFmpeg 编码与内核转换引擎
├── scanner.py                 # 文件夹巡检与状态判定工作线程
├── utils.py                   # 工具库（探针、4重锁判断、命令行运行）
├── styles.py                  # PySide6 UI 样式表 (QSS)
├── main_window.py             # GUI 主窗口与并发线程调度
└── main.py                    # 程序统一启动入口
```

## 🚀 使用说明

1. 确保 `bin/` 目录下包含 `ffmpeg.exe` 与 `ffprobe.exe`；
2. 运行 `python main.py` 启动软件；
3. 选择需要监控的视频根目录，点击 **▶ 开始自动监控与压缩** 即可。
